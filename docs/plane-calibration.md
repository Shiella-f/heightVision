# 固定平面标定与可调物理范围

适用于固定相机、普通非远心镜头、固定高度平面。板可以在平面内移动或旋转，允许 ChArUco 局部可见。该流程建立原图到当前平面的毫米映射，不提供任意高度三维测量所需的完整相机内参。

## 窗口操作

1. 相机标定页面选择“固定平面测量标定”。
2. 填写实物整板配置或导入 JSON，查看整板 ID、轴向和尺寸。滚轮缩放，中键拖动平移。
3. 添加原图，将一张设为“基准”。图案原点及 X/Y 方向由基准图固定，不要求原点实际可见。
4. 至少三个不同平面位置/角度，建议 12～20 张，覆盖目标区域及周边。相机、焦距、光圈、分辨率、板高和平整度保持不变。
5. 联合标定后检查逐图 RMS/P95/最大值和残差叠加。红点超过 2 px，黄色线段按十倍显示重投影残差。
6. 将未参与拟合的图片设为“验证”。每张仅用三个分布开的锚点求二维刚体位姿，其余角点评价毫米误差。
7. 保存 plane_calibration.yml。透视页加载该文件后自动进入固定平面模式，再打开同分辨率原图。
8. 点击原图选中心，或输入基准板毫米坐标。宽高独立支持小数，默认 310×310 mm，修改宽高保持中心不变。
9. 检查边框和覆盖报告。红框/缺失分区要求补图、移动中心或调整范围，程序不自动缩小物理范围。
10. 出图并导出最终 mirror_measurement.yml。客户仅需这个文件与原始点阵图片。

主窗口分开保存相机原图和校正图；标定使用原图。“加载平面测量包”使用最终 v2 文件实时出图，旧内参/透视加载入口保留。

当前新建板默认采用 Step06 12×9／DICT_5X5_100，旧模型加载后沿用模型所存配置。
统一透视页面的点击、默认板、相机模式和接口说明见 [选中心说明](perspective-centering.md)。

## 整板配置

下面是合成测试板配置，不能代替实物板配置：

~~~json
{
  "board_type": "charuco",
  "layout": "opencv_4_7",
  "dictionary": "DICT_6X6_250",
  "squares_x": 17,
  "squares_y": 13,
  "square_length": 30.0,
  "marker_length": 22.5,
  "min_valid_marker_num": 7,
  "min_valid_corner_num": 8,
  "interpolate_min_markers": 2
}
~~~

- squares_x 是列，squares_y 是行，均为整板方格数。MATLAB patternDims=[行,列] 不能按同顺序直接填写。
- 单位为 mm。board_size_mm 是可选板材外形，必须容纳图案，不参与毫米比例。
- marker_ids 可选：按预览的原生布局顺序给出整板全部、不重复且在字典容量内的标记 ID。省略时从 0 连续编号。
- corner_points_mm 可选：按内角点 ID 顺序给出完整 [X,Y] 实测坐标，长度为 (squares_x-1)*(squares_y-1)。
- 自定义 ID 不改变单个标记的旋转和方格布局。不支持的布局明确拒绝，真实 MATLAB 板须核对预览与实物。
- 未出现在局部照片中的整板规格无法靠照片自动核实，需要真实生成配置或板说明。

## 数学与坐标

原图点经归一化、单调径向畸变逆变换及共享单应关系，得到基准板毫米坐标；减去 ROI 左上角，得到输出毫米坐标。

联合估计共享畸变、共享平面关系及各张板的二维刚体位姿；采用零/一/二径向模型、多初值和留图验证，切向默认为零。归一化尺度固定为原图长边，模型畸变中心不声称是真实相机主点。

W/H 与整板尺寸独立，请求像素密度 p 只影响渲染：

~~~text
Nx=max(1,round(W*p)), Ny=max(1,round(H*p))
X=(u+0.5)*W/Nx, Y=(v+0.5)*H/Ny
~~~

原点是 ROI 左上边界，范围 [0,W]×[0,H]。像素中心不是边界。实际 X/Y 密度分别保存为 Nx/W、Ny/H，改变 p 不改变毫米点位。

输入/输出边长需小于 32767，输出映射/图像预算 512 MiB，超限降低 p 而不改变 W/H。支持灰度/BGR/BGRA、原地校正、映射缓存。

## 独立实物验收

拟合及留图残差基于棋盘名义/提供坐标，不代替独立计量。数学有效且覆盖满足时可调试导出，状态为 unverified。

冻结模型和 ROI，提供未参与拟合的可靠参考。JSON 字段示例：

~~~json
{
  "independent": true,
  "source": "参考件证书或独立坐标测量记录",
  "reference_uncertainty_mm": 0.02,
  "points": [
    {
      "pixel_x": 123.456,
      "pixel_y": 234.567,
      "expected_x_mm": 10.0,
      "expected_y_mm": 10.0,
      "target_id": "top_left",
      "frame_id": "独立原始帧的唯一标识"
    }
  ],
  "distances": [
    {
      "pixel_a": [123.456, 234.567],
      "pixel_b": [456.789, 234.567],
      "expected_mm": 280.0
    }
  ]
}
~~~

示例只说明字段，点数不足以通过验收。完整条件：

- 独立参考不确定度明确给出，且不超过 0.03 mm。
- 覆盖四角、四边中点、中心九个锚区。边界锚点在相应边界 10% 带，中心方向在 40%～60% 带。
- 九个锚区各至少一个目标，各目标有至少三个不同原始帧的重复测量。target_id 参考坐标一致，frame_id 不重复。
- 具有横、纵、对角长度检查，跨度至少为相应 ROI 尺寸的 80%。
- 所有位置和长度最大误差不超过 0.1 mm，重复性最大偏差不超过 0.1 mm。

通过后状态为 passed_0_1mm，否则保持 unverified 并报告缺失项。改变模型、中心或 W/H 后重新验收；仅改变渲染密度不改变物理映射。

程序依据提供的参考值及来源记录验收，不会把名义棋盘尺寸自动当作独立计量真值。

## 文件和 SDK

v1 相机+透视合并 YAML 保持兼容。v2 标记为 fixed_plane_radial、fixed_height_plane、input_stage=raw、unit=mm。

中间 plane_calibration 文件可无 ROI；最终 measurement_profile 必须有通过覆盖检查的 ROI。振镜加载中间文件、错误版本或纯内参文件会失败，并清空旧结果。

振镜签名保持：一个 YAML、原图、3/5/.../65 规格；返回对应的像素和毫米数组及五列 CSV。v2 点位越出有效域或 ROI 时整次失败。

窗口报告包括逐图原图残差、直线偏差、名义毫米残差、候选模型、覆盖及验收记录。YAML 的较长 JSON 元数据按 base64 分块保存，GetReport() 返回可读结构化对象，界面可导出 JSON。

故障定位：

- 标记不足：检查字典、曝光、清晰度及整板配置，增加可见标记。
- 候选不稳定：检查实际尺寸、平整度、板高和边缘覆盖，增加不同平面位置/角度。
- 某个方向误差明显更大：检查板 X/Y 制作比例、摆放平面和局部变形；查看残差叠加。
- ROI 越界：根据红框与 3×3 分区调整范围/中心或补图。整板不可见本身不构成失败。
- 无校正图：检查原图尺寸/类型、有效 ROI 和输入阶段，不能输入已经处理的图片。

本轮交付 Qt6 Debug/Release 插件、窗口和 SDK，OpenCV 独立打包，Qt5 旧包不更新。
